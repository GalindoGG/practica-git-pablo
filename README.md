# practica-git-pablo


## Nombre

Pablo

Este repositorio es utilizado como una practica para aprender el funcionamiento y los comandos de Git junto a GitHub

### Ramas

La rama "main" es la rama principal del proyecto, contiene la versión del repositorio y el archivo "README.md".

La rama "desarrollo" es una rama utilizada para llevar a cabo practicas y cambios. En esta rama se ha añadido una imagen con formato ".jpeg" como prueba.
